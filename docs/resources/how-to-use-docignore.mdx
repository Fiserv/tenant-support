# Working with docignore

## Documentation Guide to work with docignore

    * The docignore file should be defined as '.docignore'.

    * File should be placed into root directory of your github tenant repository.

    * Syntax
    ** `/directory/fileame.extension` -- ignore a specific file
    ** `/directory/subdirectory/**` -- ignore any files in `subdirectory` and all files in all subdirectories
    ** `/directory/subdirectory/` -- ignore files in `subdirectory` only
    ** `/directory/subdirectory` -- ignore files in `subdirectory` only
    ** `!/directory/fileame.extension` -- do not ignore a specific file (the order of entries that refer to specific files is not important)
    *** For examle, the entries
```
/directory/fileame.extension
!/directory/fileame.extension
```
and these entries
```
!/directory/fileame.extension
/directory/fileame.extension
```
are the same -- do not ignore `/directory/fileame.extension`
