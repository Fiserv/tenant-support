# SDKs

The "SDKs" section in the Developer Studio’s left navigation panel displays a product's SDK documentation.

## Enable SDKs
To enable the "SDKs" section in Developer Studio, add the following to the ```feature``` section of the ```tenant.json``` file located in the ```/config``` directory of the GitHub repository:

```json
{   
    "name": "enableSDKs",
    "value": true
}
```
