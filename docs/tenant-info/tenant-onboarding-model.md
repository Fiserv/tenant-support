# Developer Studio Onboarding Model for Contributing Teams

## Context
The Onboarding processes for both the Development and QA Teams are essential to ensure that new engineers are effectively integrated into the organization and equipped with the necessary tools and resources to succeed in their roles. This document serves as a comprehensive guide for onboarding new team members, outlining the steps and resources required for a smooth transition into the Developer Studio Team.

## Onboarding Process for the Development Team:
Refer to the [Onboarding Developer](https://enterprise-confluence.onefiserv.net/display/TOS/Onboarding+an+Engineer) for guidance on onboarding an Engineer for the Development Team.

### Developer Studio Tech Stack:
   Please refer to the [Tech Stack](https://enterprise-confluence.onefiserv.net/display/TOS/Tech+Stack) and keep it in mind when planning to onboard engineers to Developer Studio.

### Access Management:
Get started with the access requests & machine setup. Get the access set up for:

1. **MS Teams & channels**  
   Automatically added once email is set up. The team members would be added to Developer Studio Teams channel and the War room. 

3. **JIRA & Confluence pages**  
   Send Email request to Supriya - supriya.nirmale@firstdata.com for access.

4. **GitLab Request**  
   Raise a request in SailPoint: [How to request Gitlab Access](https://enterprise-confluence.onefiserv.net/display/TOS/Request+EKS+Gitlab+Access)

5. **Splunk**
   Follow [this guide](https://enterprise-confluence.onefiserv.net/display/TOS/Splunk) to get access to Splunk to access logs.

6. **Clarity**  
   Individual teams should log their time in their respective Clarity Projects within their own product.
